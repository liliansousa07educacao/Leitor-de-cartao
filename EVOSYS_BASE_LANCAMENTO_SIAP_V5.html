EVOSYS → SIAP

Base universal V5 • identifica automaticamente as disciplinas existentes no CSV • o SIAP nunca é salvo automaticamente.
Se o botão Copiar não funcionar no iPhone: toque dentro da caixa → Selecionar Tudo → Copiar.
Carregue o CSV da turma. A V5 vai procurar automaticamente colunas “- Pontos” ou “- Acertos”.
Fluxo rápido
EVOSYS → Exportar resultados → carregue o CSV aqui → escolha a disciplina → Gerar → Copiar → no SIAP abra exatamente a mesma turma e disciplina → F12 → Console → cole → Enter → confira o resumo → Salvar manualmente.
